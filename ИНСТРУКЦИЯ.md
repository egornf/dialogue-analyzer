# 📖 Простая инструкция для пользователя (понятно и без сложных терминов)

Эта программа умеет **автоматически слушать/читать звонки или диалоги из таблицы Excel**, оценивать работу менеджера по чек-листу (приветствие, выявление потребностей, отработка возражений, вежливость) и выдавать красивый итоговый отчет в Excel со всеми оценками и советами.

---

## 🟢 Шаг 1. Проверяем, есть ли на компьютере Python

Программе для запуска нужен бесплатный язык Python (версия 3.10 или новее).

1. Если Python **уже есть** — переходите сразу к **Шагу 2**.
2. Если Python **еще нет**:
   - Перейдите на официальный сайт: [python.org/downloads](https://www.python.org/downloads/)
   - Нажмите желтую кнопку **«Download Python»** и запустите скачанный файл.
   - ⚠️ **САМЫЙ ВАЖНЫЙ МОМЕНТ**: В самом первом окне установщика **ОБЯЗАТЕЛЬНО поставьте галочку внизу**:
     > ☑️ **«Add python.exe to PATH»**
   - Затем нажмите большую кнопку **«Install Now»** и дождитесь завершения.

---

## 🟢 Шаг 2. Скачиваем программу с GitHub

1. Откройте ссылку на репозиторий: **[github.com/egornf/dialogue-analyzer](https://github.com/egornf/dialogue-analyzer)**
2. Нажмите зеленую кнопку **«Code»** (вверху справа).
3. В выпавшем меню нажмите **«Download ZIP»** *(или просто [скачайте по прямой ссылке](https://github.com/egornf/dialogue-analyzer/archive/refs/heads/main.zip))*.
4. Откройте скачанный архив и **распакуйте папку** в любое удобное место (например, на Рабочий стол или в «Документы»).

---

## 🟢 Шаг 3. Установка (делается 1 раз)

Зайдите в распакованную папку программы:
1. Найдите файл с именем **`install.bat`** (или просто `install`).
2. Нажмите на него **дважды левой кнопкой мыши**.
3. Откроется черное окно — программа сама создаст нужные папки и скачает необходимые библиотеки. Это займет около 1–2 минут.
4. Когда появится надпись `[УСПЕХ] Установка успешно завершена! Нажмите любую клавишу`, нажмите клавишу Enter или пробел.

*Всё! Программа установлена и готова к работе.*

---

## 🟢 Шаг 4. Запуск и работа в программе

1. В папке программы дважды кликните по файлу **`run_gui.bat`**.
2. Черное окно запустит сервер, и через 3-5 секунд **в вашем браузере автоматически откроется удобная панель управления**.

### Как сделать анализ прямо сейчас (без сложных настроек):
1. В браузере в **левой колонке** поставьте галочку:
   > ☑️ **«Режим демонстрации (Mock)»**
2. В центральной части нажмите кнопку:
   > 📂 **«Сгенерировать тестовый файл с диалогами»** (создадутся 5 примеров звонков).
3. Нажмите большую синюю кнопку:
   > 🚀 **«Запустить анализ диалогов»**.
4. Программа за несколько секунд проанализирует звонки, покажет наглядные графики и выведет кнопку:
   > 📥 **«Скачать итоговый Excel-отчет»**.

Откройте скачанный файл в Excel — там будут две вкладки: общая сводка по отделу и подробный разбор каждого звонка по косточкам.

---

## 🟢 Шаг 5. Как загрузить свой Excel-файл со своими звонками

Ваша таблица Excel может быть очень простой. Достаточно, чтобы в ней были хотя бы две колонки:
- **Номер/ID звонка** (например, `CALL-01`, `1`, `2`);
- **Текст разговора** (сам транскрипт или диалог).

Программа **умная**: она сама понимает популярные названия колонок (`id`, `номер`, `текст`, `диалог`, `транскрипт`, `разговор`). 

Просто перетащите свой файл мышкой в поле **«Загрузите файл Excel»** в браузере и нажмите **«Запустить анализ»**.

## 🤖 Как подключить настоящую нейросеть (Ollama), чтобы анализировать «вживую»

Если вы хотите, чтобы каждый диалог оценивал реальный локальный искусственный интеллект (бесплатно и без интернета):

1. Скачайте и установите программу **Ollama**: [ollama.com/download/windows](https://ollama.com/download/windows)
2. После установки нажмите на клавиатуре кнопку **Пуск**, напишите `cmd` (Командная строка) и нажмите Enter.
3. В черном окне напишите команду:
   ```bash
   ollama run qwen2.5:7b
   ```
   *(Она скачает умную языковую модель Qwen 2.5 7B, которая отлично понимает русский язык, и запустит ее).*
4. Теперь в программе `run_gui.bat` **снимите галочку с Mock-режима** — анализировать звонки будет настоящая нейросеть!

## ❓ Частые вопросы и решение проблем

| Проблема | Что делать? |
| :--- | :--- |
| При запуске `install.bat` пишет **«Python не найден»** | Вы не установили Python или забыли поставить галочку **«Add python.exe to PATH»** при установке. Переустановите Python с этой галочкой. |
| Пишет ошибку **«Не удалось подключиться к localhost:11434»** | Локальная нейросеть не запущена. Либо включите галочку **«Режим демонстрации (Mock)»** в левой панели, либо установите и запустите Ollama (см. Шаг выше). |
| Окно браузера не открылось само после запуска `run_gui.bat` | Откройте браузер вручную и введите в адресную строку: `http://localhost:8501` |
| Как закрыть программу? | Просто закройте черное окно терминала и вкладку в браузере. |
