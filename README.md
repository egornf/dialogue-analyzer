# 🎙️ Анализатор диалогов из Excel с локальной LLM (ОКК)

Автономный Python-инструмент для автоматической загрузки транскриптов звонков и диалогов из Excel, их подиалоговой оценки по настраиваемому чек-листу с использованием **локальной языковой модели (LLM)** и формирования сводного аналитического отчета в формате `.xlsx`.

---

## 🌟 Ключевые возможности

1. **100% Локальное исполнение**: Никаких облачных API, расхода токенов и риска утечки клиентских данных. Работает полностью оффлайн через **Ollama**, **LM Studio**, **llama.cpp** или **vLLM**.
2. **Гибкий парсинг Excel**:
   - Автоматически распознает формат: 1 строка = 1 диалог (ID + Текст) или 1 строка = 1 реплика (ID диалога + Спикер + Текст).
   - Автоматический поиск нужных столбцов по ключевым синонимам (`id`, `текст`, `транскрипт`, `dialogue`, `call_id` и др.).
3. **Изолированное промптирование**: Каждый разговор оценивается в отдельном контекстном запросе со строгим возвратом JSON.
4. **Оценка по чек-листу**: Выставление баллов по каждому критерию с учетом весов, текстовое обоснование с цитатами из разговора.
5. **Агрегация и сводный анализ**:
   - Автоматический расчет метрик: средний балл (%), процент успешных диалогов (Pass Rate), рейтинги критериев.
   - Финальный аналитический синтез через LLM: общее резюме, ключевые сильные стороны, системные ошибки и рекомендации руководителю.
6. **Двухстраничный Excel-отчет**:
   - **«Сводный отчет»**: KPI-дашборд, таблица по критериям, сильные/слабые стороны, выводы и управленческие рекомендации.
   - **«Детализация»**: Строка по каждому диалогу со статусом, процентом, оценками и цитатами по каждому пункту чек-листа, общим резюме диалога и полным транскриптом.

## 🛠️ Установка и подготовка

### 1. Установка зависимостей Python
Убедитесь, что у вас установлен Python 3.10+:
```bash
pip install -r requirements.txt
```

### 2. Подготовка локальной LLM

#### Вариант А: Использование Ollama (Рекомендуется)
1. Скачайте и установите [Ollama](https://ollama.com/).
2. Загрузите желаемую модель с поддержкой русского языка и следования инструкциям:
   ```bash
   ollama pull qwen2.5:7b
   # или для мощных ПК:
   ollama pull qwen2.5:14b
   # или Llama 3:
   ollama pull llama3.1:8b
   ```
3. Убедитесь, что Ollama запущена (`http://localhost:11434`).

#### Вариант Б: Использование LM Studio / LocalAI / vLLM
1. Запустите локальный сервер (например, в LM Studio включите «Local Server» на порту 1234).
2. Задайте в `config.json` или в аргументах запуска:
   ```json
   "provider": "openai",
   "base_url": "http://localhost:1234/v1",
   "model": "ваша-модель"
   ```

## ⚙️ Настройка чек-листа (`config.json`)

В файле `config.json` можно гибко настраивать параметры модели и список критериев оценки:

```json
{
  "llm": {
    "provider": "ollama",
    "base_url": "http://localhost:11434",
    "model": "qwen2.5:7b",
    "timeout_seconds": 120,
    "temperature": 0.1
  },
  "passing_score_percentage": 70.0,
  "checklist": [
    {
      "id": "greeting",
      "name": "Приветствие и представление",
      "description": "Менеджер поздоровался, представился и озвучил компанию/цель звонка.",
      "max_score": 10,
      "weight": 1.0
    },
    {
      "id": "need_discovery",
      "name": "Выявление потребностей",
      "description": "Менеджер задавал открытые или уточняющие вопросы, внимательно слушал клиента...",
      "max_score": 10,
      "weight": 1.5
    }
  ]
}
```

## 🚀 Запуск анализа

### Быстрая проверка без GPU (Mock-режим)
Для проверки генерации таблиц и логики пайплайна без ожидания работы LLM:
```bash
# 1. Сгенерировать тестовый Excel с 5 звонками:
python create_sample_excel.py

# 2. Запустить анализ в Mock-режиме:
python main.py --mock --input sample_dialogues.xlsx --output analysis_result.xlsx
```

### Анализ с реальной локальной LLM (Ollama)
```bash
python main.py --input sample_dialogues.xlsx --output results.xlsx
```

### Дополнительные параметры CLI
```bash
python main.py --help

Параметры:
  -i, --input PATH      Путь к исходному Excel-файлу с диалогами
  -o, --output PATH     Путь для сохранения итогового файла Excel (.xlsx)
  -c, --config PATH     Путь к файлу конфигурации (по умолчанию: config.json)
  --mock                Запуск в режиме эмуляции ответов без локального LLM
  --limit N             Обработать только первые N диалогов
  --model NAME          Переопределить модель (например, qwen2.5:14b)
  --base-url URL        Переопределить URL сервера (например, http://localhost:11434)
  --provider PROVIDER   Провайдер API (ollama или openai)
```

## 📊 Формат результатов в Excel

Итоговый файл содержит 2 вкладки:
1. **«Сводный отчет»**:
   - Ключевые KPI: количество диалогов, процент прошедших порог, средний балл;
   - Сводная таблица по критериям (средний балл, % выполнения, статус);
   - Резюме модели, сильные стороны, системные точки роста и рекомендации менеджменту.
2. **«Детализация»**:
   - Построчные результаты по каждому звонку: статус (зеленый/красный бейдж), итоговый %;
   - Колонки баллов и цитат/комментариев по каждому пункту чек-листа;
   - Краткое саммари диалога и персональная рекомендация сотруднику;
   - Исходный текст транскрипта.
